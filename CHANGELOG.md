# Changelog

## 1.0.0

- First release: the Hibira Live Chat element loads the chat with the plugin's Workspace ID, with chat button, colour and language options.
- Element actions Open chat (with the sales topic), Close chat, Identify visitor and Forget visitor; the chat is ready / an error occurs events.
- Server action Hibira Live Chat - Sign user signs a user ID with the identity secret for verified visitors.
